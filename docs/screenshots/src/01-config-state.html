KeyLock — saved configuration

There is no in-game settings UI. The plugin stores whether the binds are swapped and the original 11-byte keybind snapshots in pluginConfigs/KeyLock.json.

{ "Version": 1, "Swapped": true, "OriginalBinds": { "321": "…11 bytes (MOVE_FORE was W)…", "322": "…MOVE_BACK was S…", "323": "…MOVE_LEFT was A…", "324": "…MOVE_RIGHT was D…", "348": "…JUMP was Space…" } }

After /keylock off, Swapped becomes false and OriginalBinds is cleared.

On load, if Swapped is still true, the plugin logs a warning — run /keylock off to restore.
