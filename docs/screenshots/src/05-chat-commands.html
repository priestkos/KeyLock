/keylock toggle, on, off, restore, and status read-back
> /keylock
[KeyLock] swapped 5 keybind(s): movement is on the arrow keys, Jump has no key. /keylock off restores.
> /keylock status
[KeyLock] swapped, 5 saved bind(s):
MOVE_FORE Up / unbound
MOVE_BACK Down / unbound
MOVE_LEFT Left / unbound
MOVE_RIGHT Right / unbound
JUMP unbound / unbound
> /keylock off
[KeyLock] restored 5 keybind(s).
> /keylock help
[KeyLock] /keylock [on|off|restore|status]
Illustrative chat lines — not a real client log
Bare /keylock swaps or restores depending on Swapped.
status prints the eight managed inputs from the live keybind table.
Unknown args print usage only — no chat echo for on/off.
