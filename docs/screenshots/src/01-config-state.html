Status / config — per-character state in pluginConfigs/KeyLock.json
KeyLock — saved configuration

There is no in-game settings UI. While swapped, each character's pre-swap 11-byte keybind snapshots live under Characters in pluginConfigs/KeyLock.json.

{ "Version": 1, "Characters": { "12345678901234567": { "321": "…11 bytes (MOVE_FORE was W)…", "322": "…MOVE_BACK was S…", "323": "…MOVE_LEFT was A…", "324": "…MOVE_RIGHT was D…", "348": "…JUMP was Space…" } }, "Swapped": false, "OriginalBinds": { } }

After /keylock off, that character's entry is removed from Characters. Legacy Swapped / OriginalBinds are migration-only.

On load, if saved swap state remains (Characters or legacy OriginalBinds), the plugin logs a warning — run /keylock off on that character to restore.
